# 探索問題

把模糊的想法、反覆出現的困難，整理成有依據的問題定義與可驗證的下一步。

這個技能適合在討論解法之前使用。它會透過分輪提問釐清現象、受影響的人與期望的改變；能查證的事實先查證，尚無證據的原因則明確標為假設。

## 什麼時候使用

- 只有初步想法，還說不清楚真正要解決什麼。
- 看見某個困難反覆發生，但不確定原因。
- 已想到解法，想先確認它對應的是不是關鍵問題。
- 需要把零散觀察整理成後續訪談、查證或決策的起點。

## 如何探索

1. **釐清起點**：從具體事件或觀察出發，確認誰受到影響、影響是什麼、為何現在需要處理，以及已知的資料和限制。
2. **分流並分輪處理**：可查的事實由 agent 查證；個人經驗、目標與偏好向使用者確認；需要其他人提供的資訊或決策，才列入待確認事項。每輪只問目前能回答的關鍵問題，不重複詢問已提供的資訊。
3. **整理證據與假設**：分開記錄已確認的事實、推論及待驗證假設。假設會寫明目前依據、猜錯的影響和驗證方式；具體數字須有來源，否則標為估計或假設。

時間有限時，技能會優先釐清最影響判斷的問題，並保留尚未確認的事項。

## 會得到什麼

探索結果依問題複雜度調整，通常包含：

- **問題與目標**：觀察到的現象、支持證據，以及希望改善的結果。
- **範圍**：受影響的人與情境、本輪探索的邊界。
- **下一步**：優先驗證的假設、可行的查證方式。
- **假設與待確認事項**：目前缺少什麼資訊、該向誰確認，以及答案會影響哪個判斷。

例如，當有人說「流程太複雜，應該做一個新工具」，技能會先追問最近一次卡住的情境、受影響的人和現有證據，再判斷是否值得驗證「流程複雜」這個原因，而不是直接把新工具當成結論。

## 安裝

將整個 `explore-problems` 目錄複製到使用專案的技能目錄，保留 `SKILL.md` 與 `agents/openai.yaml`。

| 工具 | 安裝位置 |
|---|---|
| Codex | `.agents/skills/explore-problems/` |
| Claude Code | `.claude/skills/explore-problems/` |

在 Codex 中，安裝後的技能檔案應位於 `.agents/skills/explore-problems/SKILL.md`。

## 使用

可以直接描述情境，例如：

> 我有個產品想法，但還不知道真正要解決的問題。先幫我探索問題。

也可以明確指定「探索問題」或在 Codex 使用 `$explore-problems`。
